# Contributing to Selfie AI Selfie

Thanks for helping develop the visual language of Selfie AI Selfie.

## Before you start

For a substantial change, open an Issue describing:

- the identity or state problem you want to solve;
- the prompt or workflow behavior that should change;
- how you will verify the change.

Small documentation fixes and narrowly scoped prompt improvements can go directly to a branch and pull request.

## Pull request expectations

- Keep changes focused and explain the user-visible result.
- Preserve the distinction between stable identity anchors and changing state variables.
- Do not add personal sensitive data, private credentials, or unlicensed reference material.
- If adding an example image, document its generation or source context and confirm that it can be redistributed.
- Update `SKILL.md`, `README.md`, or `references/prompt-patterns.md` when the behavior or installation instructions change.
- Run `quick_validate.py` against the Skill directory before requesting review.

The preferred collaboration path is: Issue → branch → pull request → maintainer review.
