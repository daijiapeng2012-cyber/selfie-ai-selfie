# 间隙：六个月的形状

The Interval · Six Months of Becoming

这是一组由六张独立自画像组成的时间序列。六个月是创作中的时间刻度；本组在同一轮生成，用形态变化表达工作方式的演进。

共同的身份来自原作《间隙》：细长的空心轮廓、半透明纸层、烟蓝色玻璃、少量铜线与琥珀色接点。它每个月改变与碎片、连接和现实之间的关系。

## 每个月的变化

1. **收拢**：先容纳一个尚未想清楚的问题。碎片停在边缘，结构仍在收拢。
2. **连结**：让分散的材料建立关联。几组相隔的薄片被细线连接起来。
3. **取舍**：让有限的注意力有方向。复杂的来路经过选择，留下清楚的几条线。
4. **落地**：让想法接触现实。下缘接触地面，延展成一座有接缝、有重量的小桥。
5. **修订**：让错误有被修改的位置。右侧结构拆开重接，旧的针孔和材料仍被保留。
6. **留白**：让下一次改变有空间。层片和连接减少，左侧保留一道修订留下的缝线。

第五个月最能表达这组作品的取向：修订留下的痕迹成为身份的一部分。第六个月保留了这道接缝，也留下了足够宽的空白。
